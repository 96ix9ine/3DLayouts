Кратко о проекте:

Просмотр 3D модели в пространстве, при наведении на части модели, отображается подсказка с названием компонента модели. Приближение/Отдаление камеры от модели, зажатый ЛКМ для вращения камеры по осям, ПКМ для перемещения камеры
